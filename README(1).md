# Tableau Practice - Retail Sales Dashboards

## Objective
Build Tableau skills by designing interactive retail dashboards for trend and category analysis.

## What I Practiced
- Interactive dashboard design: trend lines, category filters, drill-downs
- Sales and profit KPIs, Category to Sub-Category drill-down
- Regional comparison and discount vs profit-margin analysis
- Dashboard actions linking multiple views

## Tools
Tableau (Public / Desktop), Excel
